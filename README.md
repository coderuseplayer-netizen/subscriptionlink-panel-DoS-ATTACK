
## چه چیزهایی حذف/ساده شد

| مورد قبلی | جایگزین جدید | دلیل |
|---|---|---|
| `> blockquote` روی فارسی | متن ساده | blockquote + فارسی = به‌هم‌ریختگی bidi |
| `**بولد**` داخل جمله فارسی | متن ساده | bidi بولد رو جابه‌جا می‌کنه |
| هدرهای ایموجی‌دار (`## 🎯 نمای کلی`) | `## ۱. نمای کلی` | ایموجی + فارسی در هدر مشکل‌ساز بود |
| فهرست با anchor link فارسی | فهرست ساده بدون لینک | anchorهای فارسی در GitHub کار نمی‌کنن |
| جدول ویژگی‌ها با ایموجی | لیست bullet ساده | جدول + فارسی + ایموجی = جابه‌جایی ستون‌ها |
| ASCII art معماری با `┌─┐` | توضیح متنی ساده | box-drawing + RTL اطرافش به‌هم می‌ریخت |
| جدول متغیرها | لیست bullet | ستون‌های جدول با فارسی جابه‌جا می‌شن |
| `<details>` HTML برای FAQ | `###` هدرها | HTML + فارسی = به‌هم‌ریختگی |
| بخش «جدول مقایسه Rotation» جدا | ادغام در بخش Rotation | حذف جدول |

الان از خط اول تا آخر همه‌چیز LTR-safe و RTL-safe هست و روی GitHub تمیز رندر می‌شه.
